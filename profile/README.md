# ![](./mortar-board-24.svg) CodeHub Classroom

**![](./mortar-board-16.svg) CodeHub Classroom** is a desktop application aimed at making it easy to manage classroom assignments for the courses you teach. Central to this is the ability to easily **provision** GitHub repositories for you and your students.
